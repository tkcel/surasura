# Twitter リリース告知文の生成

バージョン番号: $ARGUMENTS

## 手順

1. バージョン番号の取得
   - `$ARGUMENTS` からバージョン番号を取得する（例: `0.5.0`）
   - バージョン番号がない場合はユーザーに確認する

2. リリースノートの読み込み
   - `apps/www/src/content/releases/v{VERSION}.md` を読み込む
   - ファイルが存在しない場合は、先に `/generate-release-notes` でリリースノートを生成するよう案内する

3. ツイート文の生成
   - リリースノートの内容をもとに、以下のルールでツイート文を作成する:
     - 280文字（日本語は1文字=2文字換算で実質140文字程度）以内に収める
     - 冒頭にプロダクト名とバージョン番号を含める（例: `📢 surasura v0.5.0 をリリースしました！`）
     - 主要な変更点を簡潔に箇条書きで2〜3点挙げる
     - 絵文字を適度に使ってキャッチーにする
     - 末尾にリリースノートページへのリンク `https://www.sura2.net/releases/{VERSION}` を含める
     - ハッシュタグは付けない（必要ならユーザーが後で追加する）

4. フォーマット例

```
📢 surasura v0.5.0 をリリースしました！

✨ AIモデルをGPT-5系にアップグレード
🃏 スクロール連動カードスタックを追加
📝 リリースノートシステムを導入

詳しくはこちら 👉 https://www.sura2.net/releases/0.5.0
```

5. 確認
   - 生成したツイート文をユーザーに表示して確認を求める
   - 文字数の目安も表示する
   - 修正が必要な場合はユーザーの指示に従って修正する
   - ツイート文はファイルに保存せず、会話内で完結させる
